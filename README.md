# Ifawa: Your Fa Ecosystem

PROMPT POUR LOVABLE.DEV — PROTOTYPE UI/UX DE LA PLATEFORME IFAWA

Tu es chargé de concevoir un PROTOTYPE COMPLET, MODERNE ET NAVIGABLE de la plateforme IFAWA.

IMPORTANT :
Je veux uniquement un prototype frontend / UI-UX très abouti.

NE PAS chercher à construire maintenant :
- une vraie base de données ;
- un vrai système d’authentification ;
- de vrais paiements ;
- une vraie messagerie temps réel ;
- une vraie logique serveur ;
- de vraies permissions backend ;
- une vraie administration fonctionnelle ;
- des APIs externes.

Toutes les fonctionnalités doivent être SIMULÉES avec des données de démonstration réalistes.

L’objectif est de pouvoir :
- parcourir l’application ;
- naviguer entre les écrans ;
- comprendre tous les parcours ;
- tester l’expérience utilisateur ;
- présenter le concept ;
- valider le design ;
- préparer ensuite une future version réellement fonctionnelle.

Le prototype doit être suffisamment crédible pour donner l’impression d’un produit déjà très avancé.

==================================================
1. NOM DU PRODUIT
==================================================

Nom officiel de la plateforme :

IFAWA

Toujours utiliser IFAWA dans l’interface.

Créer un logo temporaire simple et premium à base du mot :

IFAWA

Le logo définitif sera remplacé plus tard.

==================================================
2. POSITIONNEMENT DE IFAWA
==================================================

IFAWA est une plateforme numérique moderne consacrée au Fa.

Elle réunit :

- connaissance ;
- communauté ;
- découverte ;
- mise en relation ;
- services liés au Fa ;
- accompagnement des initiés ;
- espace personnel.

La plateforme doit servir à la fois :

- aux personnes déjà initiées ;
- aux personnes non encore initiées.

Elle doit donner l’impression d’un véritable écosystème numérique autour du Fa.

==================================================

L’application doit être TRÈS SIMPLE À UTILISER.

La logique d’utilisation doit être fortement inspirée des habitudes de Facebook.

L’objectif est qu’une personne habituée à Facebook comprenne presque immédiatement comment utiliser IFAWA.
